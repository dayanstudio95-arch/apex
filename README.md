# APEX

אפליקציית אימונים בעברית: מאמן חכם שבונה תוכנית ומעלה עומס לבד, רצף שבועי, XP ורמות, הישגים ומעקב התקדמות.

**פותחים ב-Safari באייפון → שיתוף → הוספה למסך הבית.**

- כל הנתונים נשמרים רק במכשיר (IndexedDB). אין שרת ואין חשבון.
- עובדת גם בלי אינטרנט (PWA).
- מאגר התרגילים והתמונות: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (נחלת הכלל).
- תוכנית לפי אזורי גוף: פול באדי, A-B או A-B-C, עם מספר תרגילים לכל אזור. בטן ופינישר נכנסים בסוף אם יש זמן.
- מיקומים עם ציוד מדויק, כולל מולטי טריינר ביתי (פולי עליון/תחתון, לחיצת חזה, פרפר, פשיטת/כפיפת ברכיים) ומגבלות משקל (משקולות עד X, פלטות של Y ק״ג).
- תרגילים מועדפים (⭐) שהמאמן בוחר קודם, וזמני מנוחה אישיים: בין סטים, בין תרגילים ולתרגיל מסוים.

## פיתוח
```bash
npm install
npm run dev      # http://localhost:5173/apex/
npx vitest run   # בדיקות המנוע
npm run build
# עדכון מאגר התרגילים (אחרי עריכת tools/exercise_curation_he.json):
python3 -I ../tools/build_exercise_db.py <תיקייה-זמנית> --web
```
כל דחיפה ל-`main` בונה ומפרסמת אוטומטית ל-GitHub Pages.
